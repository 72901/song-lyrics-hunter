# 双语歌词排版规范

用户明确认可的格式。照抄，不要自由发挥。
生成请直接用 `scripts/build_delivery.py`，不要手搓脚本。

## 完整样例（当前标准，v1.1）

```
《春嵐》
词曲：john
演唱：john feat. 初音ミク
时长：2:42 · 时间轴精度：毫秒（人声峰校验 吸附后命中率 100% / 平均偏差 0.03s）
==== 【A段：虚像に塗れた私】 ====
[00:14.680] 虚像に塗れた私 まるで神様みたいね
[00:14.680] 浑身布满虚像的我  简直就像神明一样呢
[00:17.860] 本当の気持ちとか知ったかぶりで
[00:17.860] 假装明白我真正的心情
```

## 规则

1. **头部四行**：`《标题》` ／ 词曲编 ／ 演唱 ／ 时长+精度
2. **小节标题独立一行**：`==== 【中文标题】 ====`，前后不加空行
3. **日文行在前，中文行紧跟**，两行时间戳完全相同
4. 时间戳 `[mm:ss.mmm]` 三位毫秒，不要因为加译文就退回秒级
5. 纯英文句（`I've been thinking about you`）没有译文就只留一行，**不要硬塞机翻**
6. 引号台词 `「」` 在译文里保留 `「」`
7. 译文意译，不要逐字直译；语气词（`へー`、`ねえ`、`うるせえ`）要翻出情绪
8. 文件名 `<歌名> (双语歌词) - <作者>.txt`，与纯原文版并存，**不覆盖**

> 早期版本用三行 banner（`====` 行包裹标题 + 空行）也交付过，属兼容格式；
> 新歌统一用上面的单行 `====` 形式，与近 20 套交付保持一致。

## 小节标题怎么写

不要只写"第一段/第二段"。用**内容概括 + 原句开头**，让读者一眼知道这段在讲什么：

| 段落内容 | 标题 |
|---|---|
| 开场 | 【开场：花散りて】 |
| 主歌 | 【A段：虚像に塗れた私】 |
| 副歌（重复出现） | 【副歌：春の嵐呼んだ】、【副歌 2】 |
| 桥段 | 【B段：思想が乾いた私】 |
| 间奏 | 【间奏】 |
| 结尾高潮 | 【终段：から紅の紅葉達さえ】 |

- 歌名/首句太长的，截前 6–10 个假名即可
- 同一旋律重复时，第二遍写【副歌 2】或【D段：…】，不要两张一样的标题

## 元信息行的写法

```
词曲：john
作词：倉木麻衣 ／ 作曲・编曲：徳永暁人
```

- 词曲同一人 → `词曲：X`
- 分开写时用全角空格 `　` 或 ` ／ ` 分隔，不用半角逗号
- 查不到编曲就不写，**别编**

## 精度指标怎么写

```
时长：2:42 · 时间轴精度：毫秒（人声峰校验 吸附后命中率 100% / 平均偏差 0.03s）
```

- 数字来自 `lyrics_sync.py`，如实抄，100% 就写 100%
- 用了放宽容差（0.6s）才达标的，要在这里说明：`吸附后命中率 95% / 平均偏差 0.03s（容差 0.6s，弱起唱法）`

## 纯原文版（另一份文件）

```
《衛星》
词曲：柿崎ユウタ
演唱：柿崎ユウタ
时长：2:22 · 时间轴精度：毫秒（人声峰校验 吸附后命中率 92% / 平均偏差 0.08s）
[00:12.440] あなたはいつも私のことを
[00:15.040] ぐるぐるぐるぐる振り回す
```

- 默认带头部四行（与既有交付一致）
- 无小节标题、无空行、无译文——喂播放器直接用
- 需要极致干净的版本加 `--plain-no-header`

## 译文质量守则

1. **先信网易云 `tlyric`，但不盲信**：官方译文质量普遍好，缺句/错位才是问题
2. **缺句必须补**，`build_delivery.py` 输出的 `missing_rows` 要清零
3. **错位要重译**：整段译文对不上原文（《神のまにまに》第二段、《Mr. "Broken Heart"》人称错乱）→ 直接用自己的 `TRANS` 列表逐句重写
4. **梗要保留**：`クラッピョヘンザ`（clap your hands up 的戏仿）、`エビデイ エビナイ`（every day / every night）这类谐音，译成中文会丢，保留英文并加简短注释最稳
5. 补译的句子要与前后文语气一致，不要突然书面化
